# BarClode Battler

**BarClode Battler** — a nod to Claude, who builds it — is a browser remake of Epoch's 1991 **Barcode Battler II**: type (later, scan) an
EAN barcode, it becomes a warrior, item or enemy, and cards fight — versus,
story and scanned-enemy modes. Static site, hosted on GitHub Pages from `docs/`.

- Play: https://kelu124.github.io/barcodebattler/ (once deployed)
- Dev: `python3 -m http.server 8737 -d docs` · tests: `npm test`
- Rules and sources: `.claude/skills/bb-game-rules/`, `.claude/projects.md`

[finalfighter/BarcodeBattler2-Simulator](https://github.com/finalfighter/BarcodeBattler2-Simulator) (MIT)
